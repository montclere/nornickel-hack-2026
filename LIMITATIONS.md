# Ограничения веб-сервиса (важно)

Сервис — **локальный инстанс** для тестирования (жюри), НЕ публичный продакшн.

## Безопасность / приватность
- **Не публичный.** В `docker-compose.yml` порт проброшен только на `127.0.0.1`. Не выставляйте
  наружу без обратного прокси с TLS и аутентификацией.
- **Нет аутентификации и многопользовательской изоляции по безопасности.** Прогоны разделяются
  только непубличным `run_id` (кто знает id — видит прогон). Для общего доступа нужен auth-слой.
- **Данные фабрик наружу не отправляются.** Загруженные материалы лежат локально в
  `outputs/runs/<run_id>/sources/`. Во внешние сервисы уходят ТОЛЬКО производные термины запроса:
  - OpenAlex (научные статьи) — обезличенные англ. ключевые слова вмешательства;
  - веб-поиск (DuckDuckGo/Yandex Search) — то же;
  - Yandex LLM/OCR — только тексты фрагментов ЗНАНИЙ (reference) и, при OCR, картинки знаний.
  Хвосты (`data/`, state) в LLM/поиск не уходят — ветка А полностью детерминирована и локальна.
- **Селф-хостинг LLM:** контракт `LLMClient` (webapp/interfaces/llm.py) позволяет подставить свою
  модель — тогда наружу не уходит вообще ничего, кроме поиска (который можно выключить).

## Функциональные
- **Ветка Б и полировка требуют LLM.** Недоступен ключ/эндпоинт → эти шаги пропускаются
  (preflight), детерминированные ветки (хвосты, досье OpenAlex, веб-практики) работают без LLM.
- **Веб-практики — best-effort.** DuckDuckGo бот-блокирует по IP → возможен пустой результат
  (не падаем). Для стабильности подключается Yandex Search API (adapters/yandex_search.py).
- **Прогон синхронный** (в threadpool). Долгий корпус может занять минуты; для интерактива
  запланированы фоновая задача + прогресс через SSE (см. PLAN.md).
- **Конкурентные прогоны** делят глобальную телеметрию (`factory.client.TELEMETRY`) — для
  локального одиночного использования ок; под многопользовательскую нагрузку нужна изоляция.

## Лимиты загрузки (webapp/config.py)
- Суммарный размер: `WEBAPP_MAX_UPLOAD_MB` (по умолчанию 60 МБ), число файлов: `WEBAPP_MAX_FILES` (40).
- Допустимые типы: xlsx/csv/pdf/docx/txt/md + изображения (png/jpg/tiff/webp/bmp).
