# План развития «Фабрики гипотез»

Поверх рабочего гибридного ядра (детерминированная ветка А + LLM-ветка Б, обе оттестированы).
Принцип: **одна крепкая фича, которая не падает > кучи сырых**. Агент и FastAPI — потом.

## 1. Модуль «мировые практики» (веб-поиск)  ✅ ГОТОВО
Заполняет `world_practice` каждой гипотезы внешним подтверждением из промышленности.
- [x] `factory/websearch.py`: поиск → загрузка → LLM-выжимка с цитатным гейтом (URL + дословная цитата), кэш по отпечатку.
- [x] Приоритет промышленных доменов, двуязычно (RU/EN), деградация без сети/ключа → `None`.
- [x] Встроено в `flex.py --web`, показано в отчёте (цитата + кликабельный источник).
- [x] Оттестировано adversarial (10/10 на подставных страницах+LLM): галлюцинация/`found=false`/мусор → `None`.

## 2. Доказательное досье гипотезы (главная вау-фича)  ← СЛЕДУЮЩЕЕ
Цель (по QA стр.109): «каждая гипотеза подтверждена набором знаний, как решают в мировой
практике, причины, важность». Не один источник — **ряд**: статьи + новости/блоги/посты.
- [ ] **OpenAlex как костяк** (JSON API, без ключа, стабилен — надёжнее скрейпинга, который
      сейчас 403-ит у половины сайтов): статьи + `cited_by_count` («важность») + abstract
      («причины/механизм»), цитата ⊂ abstract (тот же гейт).
- [ ] Мой `websearch` — garnish для грани «внедрено на фабрике X» (вендоры грузятся), с graceful-fallback.
- [ ] Панель-досье в HTML: 3-5 источников на гипотезу, отсортированы по релевантность×цитируемость.
- [ ] Связь с новизной: практика найдена → проверено, но НЕ ново; не найдена → потенциально
      ново (QA: «что не применено на производстве — новизна»). Показывать оба сигнала.
- [ ] Materials Project (свойства минералов) — ОТЛОЖИТЬ: ещё ключ и зависимость против принципа «одна крепкая фича».

## 3. Единый клиент внешних вызовов + метрики  ← ИНФРАСТРУКТУРА ПОД СЕРВИС
Вынести LLM- и HTTP-клиент в ОДНО место с общей политикой.
- [ ] `factory/client.py`: асинхронный HTTP + LLM, ретраи/backoff/джиттер (уже есть — свести сюда),
      бюджет времени на источник + circuit-breaker (не висеть на мёртвом источнике).
- [ ] **Адаптер LLM-эндпоинта**: хотите — селфостите свою модель, подставляете URL/пути, работает
      так же; на демо — Yandex. Закрывает приватность: данные фабрик наружу не уходят, только к Yandex.
- [ ] **Учёт всех метрик** (бизнес + dev): токены, задержки, кол-во вызовов/ретраев/кэш-хитов,
      время обработки. `outputs/run_metrics.json` — «инфа про работу системы».
- [ ] Эмпирически замерить зависимость времени от объёма корпуса (демо ≤3 мин, видео 5 мин).

## 4. Критик (LLM-разбор гипотезы)
Не влияет на скор — помощь ресёрчеру. Врастает из judge.py.
- [ ] `factory/critic.py`: риски/слабые места/что проверить, БЕЗ цифр (числа — за метриками).
- [ ] Судейская рубрика: **добавить якоря шкалы** (что такое «3» vs «5») — сейчас даёт ~4.4 всем,
      слабо дискриминирует. Улучшить, когда доступна инфра LLM.

## 5. OCR — связать и улучшить
Схемы флотации ужасного качества, машиночитаемых версий не будет, но инфа по процессам ценна
(QA: «круто, если будет ссылаться и брать во внимание»).
- [ ] Предобработка перед OCR: grayscale, автоконтраст, upscale, бинаризация/деноизинг (для картинок и растр-PDF).
- [ ] Проверить сквозной путь скан → текст → извлечение (fuzzy-гейт готов), когда OCR-роль ключа будет доступна.

## User-фичи: визуальные улучшения (когда будет фронт/сервис)
Отдельный трек — не логика, а как это ВИДИТ и трогает пользователь. Сейчас отчёт статичен.

- [ ] **Интерактивный граф** вместо статичного SVG: зум/пан, перетаскивание узлов, подсветка
      соседей по клику, фильтр по слою (элемент/класс/форма) и по извлекаемости.
- [ ] **Раскрываемые карточки** вместо простыни списком: свёрнуто — заголовок+impact+приоритет;
      разворот — эксперимент, заземление, источники, критика, досье.
- [ ] **Прокликиваемые источники до места**: клик по цитате → открывает PDF/страницу на нужном
      абзаце/странице (`#page=N`, текстовый фрагмент-хайлайт), а не просто на документе.
- [ ] **Разложение приоритета** прямо в карточке: мини-бар «impact × addressability × clarity ×
      feas × conf», чтобы эксперт видел, ПОЧЕМУ #1 выше #2 (а не только итоговое число).
- [ ] **Панель-досье гипотезы**: источники карточками с цитируемостью, «внедрено на фабрике X»
      значком, ссылками; сортировка/фильтр.
- [ ] **Тумблер «факт / наша оценка»**: подсветить, что взято из данных, а что — наша эвристика
      (прозрачность без подтасовки).
- [ ] **Живой прогресс** извлечения (SSE): полоса «обработано N фрагментов», а не молчаливое ожидание.
- [ ] **Экспертная настройка весов** ранжирования (ползунки) — кейс прямо просит «задавать веса
      критериев»; пересчёт приоритета на лету.
