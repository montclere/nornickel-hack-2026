# План развития «Фабрики гипотез»

Поверх рабочего гибридного ядра (детерминированная ветка А + LLM-ветка Б, обе оттестированы).
Принцип: **одна крепкая фича, которая не падает > кучи сырых**. Агент и FastAPI — потом.

## 1. Модуль «мировые практики» (веб-поиск)  ✅ ГОТОВО
Заполняет `world_practice` каждой гипотезы внешним подтверждением из промышленности.
- [x] `factory/websearch.py`: поиск → загрузка → LLM-выжимка с цитатным гейтом (URL + дословная цитата), кэш по отпечатку.
- [x] Приоритет промышленных доменов, двуязычно (RU/EN), деградация без сети/ключа → `None`.
- [x] Встроено в `flex.py --web`, показано в отчёте (цитата + кликабельный источник).
- [x] Оттестировано adversarial (10/10 на подставных страницах+LLM): галлюцинация/`found=false`/мусор → `None`.

## 2. Доказательное досье гипотезы (главная вау-фича)  ✅ ЯДРО ГОТОВО (без LLM)
Цель (по QA стр.109): «каждая гипотеза подтверждена набором знаний, причины, важность».
- [x] **OpenAlex как костяк** (`factory/openalex.py`, JSON API, без ключа, БЕЗ LLM): статьи +

- [x] Панель-досье в HTML: до 3 источников на гипотезу, ранг релевантность×цитируемость, кликабельно.
- [x] Проверено вживую: реальные статьи с DOI и цитируемостью, заземлённые цитаты.
- [x] `websearch` (`--web`) — garnish для грани «внедрено на фабрике X», с graceful-fallback.
- [ ] Связь с новизной: практика найдена → проверено/не ново; не найдена → потенциально ново — показать оба сигнала.
- [ ] Materials Project — ОТЛОЖЕНО (лишний ключ/зависимость).
- [ ] «Настоящий рост» (новости/блоги/тренды) — позже, поверх того же гейта.

## Надёжность внешних источников (важно для демо)
- Веб-поиск (`--web`) сделан ДЕТЕРМИНИРОВАННЫМ (без LLM) и ищет русских соседей, НО
  зависит от DuckDuckGo, который бот-блокирует по IP (в песочнице сейчас отдаёт 202).
  На чистой машине работает; для стабильности перед сервисом — перейти на **Yandex Search
  API** (свой ключ, надёжно, тот же стек) как основной бэкенд поиска, DDG — fallback.
- OpenAlex (`--dossier`) — надёжный костяк (API без ключа), не зависит от скрейпинга.

## Позже (FastAPI-сервис)
- Async-клиент (сейчас sync в `client.py`), health-check (проверка ключа Yandex до приёма запроса).
- Длинное извлечение как фоновая задача с прогрессом через **SSE** (Server-Sent Events —
  сервер стримит «обработано N» в браузер по одному HTTP-соединению, проще вебсокетов).
- **Контекст пользователя между запусками (изоляция):** каждый прогон — свой `run_id`
  (папка `outputs/<run_id>/`: кэши графа/досье/OCR/метрик, HTML). Разные пользователи/сессии
  не конфликтуют по кэшу и отчётам. Опционально — привязка к user_id при появлении авторизации.
- **Хранение источников для ссылок-цитат (без пересылки наружу):** загруженные материалы
  кладём в `outputs/<run_id>/sources/`, отдаём статикой; локатор цитаты (`файл:стр.N` или
  `Хвосты.xlsx!E204`) превращаем в ссылку `/<run_id>/sources/<file>#page=N`, открывается в
  НОВОЙ вкладке на нужном месте. Данные фабрик остаются локально, наружу не уходят
  (адаптер LLM/поиска можно указать на селф-хост — см. §3).
- Лёгкий агент-оркестратор.
- H3: предсказательная модель крупность↔извлечение (6 точек/фабрику — мало; на потом).
- Экспорт PDF/DOCX/CSV/JSON(Jira).

## User-фичи: визуальные улучшения (когда будет фронт/сервис)
Отдельный трек — не логика, а как это ВИДИТ и трогает пользователь. Сейчас отчёт статичен.

- [ ] **Интерактивный граф** вместо статичного SVG: зум/пан, перетаскивание узлов, подсветка
      соседей по клику, фильтр по слою (элемент/класс/форма) и по извлекаемости.
- [ ] **Раскрываемые карточки** вместо простыни списком: свёрнуто — заголовок+impact+приоритет;
      разворот — эксперимент, заземление, источники, критика, досье.
- [ ] **Прокликиваемые источники до места**: клик по цитате → открывает PDF/страницу на нужном
      абзаце/странице (`#page=N`, текстовый фрагмент-хайлайт), а не просто на документе.
- [ ] **Разложение приоритета** прямо в карточке: мини-бар «impact × addressability × clarity ×
      feas × conf», чтобы эксперт видел, ПОЧЕМУ #1 выше #2 (а не только итоговое число).
- [ ] **Панель-досье гипотезы**: источники карточками с цитируемостью, «внедрено на фабрике X»
      значком, ссылками; сортировка/фильтр.
- [ ] **Тумблер «факт / наша оценка»**: подсветить, что взято из данных, а что — наша эвристика
      (прозрачность без подтасовки).
- [ ] **Живой прогресс** извлечения (SSE): полоса «обработано N фрагментов», а не молчаливое ожидание.
- [ ] **Экспертная настройка весов** ранжирования (ползунки) — кейс прямо просит «задавать веса
      критериев»; пересчёт приоритета на лету.
