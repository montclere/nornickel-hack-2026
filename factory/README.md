# factory/ — ядро

Детерминированное ядро фабрики гипотез. Вся логика и метрики считаются из данных;
LLM — только чтобы понять текст литературы/сканов, и любая связь принимается лишь при
дословной цитате в источнике. Ниже — каждый модуль в паре строк: что делает.

## Корень (оркестрация и настройки)
- **config.py** — все константы (env-override): пути, кэши, лимиты, ключи, пороги.
  Единственное место правки поведения.
- **pipeline.py** — `HypothesisFactory`: один отчёт → профиль → гипотезы → метрики →
  HTML. Собирает трек А в единый поток.
- **flex.py** — гибкий приём «что угодно» (папка/файлы) → сам определяет хвосты vs
  литературу → трек А и/или трек Б.
- **batch.py** — прогон набора KPI × все фабрики, сводка CSV/JSON.
- **runconfig.py** — запоминает параметры последнего запуска (удобство CLI).
- **`__main__.py`** — точка входа `python -m factory <отчёт.xlsx> --kpi …`.

## tracka/ — трек А: из данных по хвостам (детерминированно, без ключей)
- **reader.py** — читает Excel по схеме: классы крупности, тоннаж металлов, формы,
  флаг «извлекаемо». Каждое число привязано к ячейке.
- **schema.py** — всё формат-специфичное знание отчёта (адреса ячеек, словари форм),
  вынесено из логики.
- **schema_bootstrap.py** — предлагает схему для НЕЗНАКОМОГО формата через LLM
  (разовая задача, вне пайплайна).
- **rules.py** — доменные правила диагноза: доминирующая форма × крупность → семейство
  вмешательства и список интервенций.
- **metrics.py** — безразмерные метрики из данных: impact, addressability, clarity,
  confidence, feasibility и их свёртка priority (открытая формула).
- **generator.py** — собирает гипотезы: диагноз + метрики + эксперимент + дорожная карта;
  Ni/Cu раздельно; `breadth` — разнообразие, `max_hyps` — порог топ-N.
- **roadmap.py** — три этапа с критериями перехода го/стоп (лаборатория→пилот→внедрение),
  шаблон по семейству.
- **knowledge.py** — граф профиля потерь (элемент→класс→форма) для послойного SVG.
- **analysis.py** — кривая раскрытия по крупности и таблица форм.
- **intent.py** — из KPI достаёт целевой металл и ограничения (словарь, детерминированно,
  без LLM).

## trackb/ — трек Б: из литературы (нужен LLM)
- **ingest.py** — pdf/docx/xlsx/картинки → текстовые фрагменты (OCR по требованию).
- **extract.py** — LLM извлекает связи `A—тип→B` с ОБЯЗАТЕЛЬНОЙ дословной цитатой
  (гейт: цитата — подстрока фрагмента). Отбор фрагментов по терминам запроса.
- **kgraph.py** — канонический граф из извлечённых связей (дедуп, нормализация).
- **discover.py** — генерирует гипотезы: разрывы Свонсона + прямые связи, ранг по
  новизне·релевантности; жёсткое заземление на металл фабрики (режет золото и пр.).

## enrich/ — обогащения (детерминированно, с цитатным гейтом)
- **websearch.py** — веб-поиск дословной фразы про вмешательство + металл фабрики
  (это упоминание, не проверенное внедрение).
- **openalex.py** — научные статьи по гипотезе с цитируемостью, заземлённые на элемент.
- **litsupport.py** — привязка цитат выданного корпуса к карточкам трека А (IDF-взвешивание).
- **bridge.py** — A×B: диагноз трека А × узлы СХЕМЫ фабрики из трека Б → адресная гипотеза.

## render/ — оформление
- **report.py** — HTML трека А: послойный SVG-граф + карточки гипотез.
- **report_kb.py** — HTML трека Б: граф литературы + карточки открытий.
- **export.py** — JSON/CSV/Jira/PDF/DOCX поверх единого `serialize` (числа совпадают с HTML).
- **glossary.py** — объяснялка «как читать граф, кривую, метрики».

## evals/ — оценка и эксплуатация
- **evaluate.py** — покрытие эталона организаторов (Гипотезы*.docx) семействами.
- **benchmark.py** — сводный евал по всем фабрикам (golden-coverage + опц. судья).
- **judge.py** — LLM-судья: 5 осей (обоснованность/правдоподобие/релевантность/новизна/
  проверяемость) 1..5, кэш; оценочный слой, не в ранге.
- **feedback.py** — вердикты эксперта из CSV → детерминированный ре-ранк.

## ext/ — внешний слой
- **client.py** — единая точка ВСЕХ внешних вызовов (LLM/OCR/веб/OpenAlex): ретраи,
  backoff, метрики (`run_metrics.json`).
- **llm.py** — клиент Yandex GPT; используется только для оформления текста и извлечения.
- **ocr.py** — Yandex Vision OCR: картинки/сканы → текст.
- **imageprep.py** — предобработка картинки перед OCR (только Pillow).
