# Бейзлайны «Фабрики гипотез»

## Главное: полностью автоматический пайплайн

**Человек делает две вещи — кладёт материалы в папку и задаёт KPI. Всё остальное авто:
парсинг, извлечение знаний, генерация, оценка. Никаких конфигов и фактов руками.**

| Бейзлайн | Роль | Метод | Запуск |
|---|---|---|---|
| **[A · grounded-фабрика](A_grounded_generation/)** | 🥇 **основной** | авто-ingest → авто-граф (LLM+цитатный гейт) → RAG-генерация + измеримая новизна | `uv run python A_grounded_generation/run.py --materials <папка> --kpi "<цель>"` |
| **[B · LBD-разрывы](B_lbd_gaps/)** | подстраховка (другой угол) | детерминированные разрывы Свонсона по **тому же авто-графу** | `uv run python B_lbd_gaps/run.py` |

Общее авто-ядро — [common/](common/): `ingest.py` (PDF/XLSX/DOCX/TXT), `extract.py`
(LLM-извлечение графа + цитатный гейт), `llm.py` (Yandex AI Studio: чат + эмбеддинги).

```bash
# демо на реальном корпусе (справочник по флотации + инструкция + Excel хвостов)
uv run python A_grounded_generation/run.py --materials materials \
  --kpi "снизить потери никеля с отвальными хвостами флотации"
uv run python B_lbd_gaps/run.py     # другой угол на том же графе
```

### Принципы (ответ на требования кейса)

- **Ноль ручного знания** — граф связей извлекается LLM из документов с проверкой
  дословной цитатой; новизна не заявляется, а считается эмбеддинг-расстоянием.
- **Grounding-контракт** — цитатный гейт при извлечении + critic-гейт при генерации.
- **Провенанс** — каждый факт кликается до страницы PDF / ячейки Excel.
- **Универсальность** — сменил папку материалов и KPI → другой домен, код тот же.

### Мечта про агента-поисковика

`common/llm.py` — готовая точка: тот же клиент вызывается в цикле «план → поиск →
генерация → критика». Основной бейзлайн уже делает один проход RAG; добавление
tool-loop (веб/Semantic Scholar) превращает его в агента.

## Ранние прототипы (01–05) — иллюстративные, НЕ основной путь

Папки `01_*`…`05_*` — первые срезы идей на **stdlib/оффлайн**. Часть из них содержит
**доменное знание, вписанное руками** (корпус, библиотека вмешательств, факты) — именно
поэтому основным сделан автоматический пайплайн (A/B), где знание извлекается из данных.
Прототипы полезны как быстрые демонстрации отдельных механик:

| # | Механика | Статус |
|---|---|---|
| 01 | LBD/Свонсон по ручному корпусу | иллюстрация метода (граф вместо памяти LLM) |
| 02 | диагностика по реальному Excel хвостов | честный диагноз из данных, но библиотека вмешательств — руками |
| 03 | анти-граф провалов (память о граблях) | механика верная, кладбище — заглушка |
| 04 | LLM-генерация с grounding-гейтом | предшественник A (факты подавались руками) |
| 05 | извлечение фактов из docx (цитатный гейт) | компонент, поглощённый `common/extract.py` |

Их идеи перенесены в автоматическое ядро. Если нужно — прототипы можно удалить.

## Секреты и зависимости

Бейзлайны 01–03 — чистый stdlib, оффлайн.
