# Бейзлайн 01 · Литературный LBD (разрывы Свонсона)

## Что демонстрирует

Универсальный движок генерации гипотез из **текста**: корпус → триплеты → граф знаний →
поиск **незакрытых звеньев** A→C (есть A→B и B→C, но прямой связи A→C нет — классический
Literature-Based Discovery Свонсона) → проверяемая гипотеза с цепочкой-обоснованием.

Ключевое: гипотеза рождается из **топологии графа**, а не из памяти модели → это «не
чёрный ящик». Любое звено кликается до исходного предложения (провенанс).

## Откуда данные

Домены — во внешних `domains/*.json` (в коде доменных строк НЕТ): `corpus` (мини-набор
«абстрактов»), `relations` (лексикон связей), `kpi_keywords`, `stopwords`. Идут два домена:
`flotation.json` (Cu-Ni) и `alloys.json` (жаропрочные сплавы). В проде корпус = реальные
статьи/патенты/отчёты (Semantic Scholar, arXiv, внутренние PDF), а правиловый экстрактор
триплетов заменяется LLM со structured output.

## Запуск

```bash
python run.py                                        # домен по умолчанию (flotation)
python run.py domains/alloys.json                    # другой домен — тот же движок
python run.py domains/flotation.json domains/alloys.json   # оба подряд
```

**Проверка универсальности:** на `alloys.json` движок без единой правки кода выдаёт
`ниобий/ванадий → дисперсные карбиды/мелкозернистость → жаропрочность` — флагманский
пример из ТЗ. Смена домена = смена JSON.

## Что говорить на защите

1. **Источник гипотезы — граф, а не LLM.** Показываем цепочку A→B→C с цитатами из
   конкретных документов. Пример находки: `магнитная сепарация → раскрытие пентландита →
   извлечение никеля` — связь, которой напрямую в корпусе нет.
2. **Скрытые негативные эффекты.** Движок находит и разнознаковые цепочки: `тонкое
   измельчение → шламы → снижает извлечение меди` — предупреждение, а не только «сделай X».
3. **Экспертная корректировка вживую (шаг 6).** Двигаем вес риска (`-1.0 → -3.0`) —
   порядок гипотез меняется предсказуемо, рискованные цепочки опускаются. Прозрачный
   скоринг = редактируемые веса, а не вердикт из модели.
4. **Универсальность физически, не на словах.** В `run.py` нет ни одного доменного
   слова; прогон `domains/alloys.json` тем же движком — доказательство, а не декларация.

## Критерии кейса

вход (литература) · генерация из знаний · проверяемость · интерпретируемость (цепочка+цитаты)
· экспертная корректировка (веса).

## Где агент-поисковик

`research(query)` (шаг 7) — сюда подключается проверка новизны кандидата по внешним базам
(«не запатентовано ли / не опубликовано ли уже A→C»).
