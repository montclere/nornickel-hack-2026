# Бейзлайн 04 · LLM-генератор гипотез (Yandex AI Studio)

## Что демонстрирует

LLM как **языковой слой над заземлёнными фактами**, а не чёрный ящик. Модель
(**YandexGPT** через Yandex AI Studio) получает KPI + список фактов-с-источниками и
возвращает **строгий JSON** гипотез ЕСЛИ/ТО/ПОТОМУ ЧТО с оценками и полем `uses_facts`.
Затем **grounding-гейт (критик)** проверяет, что каждая гипотеза ссылается на реально
поданные факты — выдумки помечаются ⚠. Это реализация связки «генератор + критик +
grounding-контракт» из проектного решения, но на живой модели.

## Откуда данные и секреты

- **Домены** — `domains/*.json` (`kpi`, `constraints`, `facts` с `id`+`source`). Идут
  два: `flotation.json` (факты заземлены до **ячеек реального Excel** хвостов, напр.
  `Хвосты ТОФ_2.xlsx:D33`) и `alloys.json`. В коде доменных строк нет.
- **Секреты** — `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` из `.env` (**в .gitignore**, в git
  не попадают). Шаблон — `.env.example`. Ключи в код не зашиты.

## Запуск

```bash
cp .env.example .env   # и вписать ключи (уже сделано для хакатона)
python run.py                        # домен flotation, реальный вызов YandexGPT
python run.py domains/alloys.json    # другой домен — тот же движок
```

Нет ключа/сети → мягкий оффлайн-фейк, бейзлайн всё равно отрабатывает (для CI/демо без сети).

## Что говорить на защите

1. **Grounding-контракт живьём.** Модель просят ссылаться только на поданные факты;
   критик отбраковывает несуществующие ссылки. LLM физически не может протащить факт,
   которого мы не дали. Гипотезы кликаются до **ячейки Excel** источника.
2. **Структурный выход, не «простыня».** Ответ — JSON-карточки с новизной/риском/ценностью
   и протоколом → сразу ранжируются и экспортируются.
3. **Локальность/безопасность (для будущего).** Тот же интерфейс `llm.py` меняется на
   локальную модель (кейс требует офлайн для конфиденциальных данных) — движок не трогаем.
4. **Универсальность.** Прогон `domains/alloys.json` тем же кодом даёт грамотные гипотезы
   в другом домене (ниобий + отжиг Y → карбиды → жаропрочность).

## Связь с другими бейзлайнами

Факты для контекста LLM — это ровно выход **бейзлайна 02** (профиль потерь по хвостам).
Полученные гипотезы можно прогнать через **бейзлайн 03** (память о граблях). Итог: 02
даёт заземление → 04 формулирует → 03 отсеивает повторы → ранкер приоритизирует.

## Критерии кейса

прозрачность/обоснованность (grounding) · структурный вывод · проверяемость (протокол) ·
мультиязычность (YandexGPT RU) · гибкость входа · экспорт JSON.

## Где агент-поисковик

`llm.py` — готовая точка для агента: тот же клиент вызывается в цикле «план → поиск →
генерация → критика». Сейчас один проход; добавление tool-loop превращает его в агента.
