# Бейзлайн 03 · Анти-граф провалов (память о граблях)

## Что демонстрирует

Прямое попадание в критерий кейса **«снижение зависимости от субъективного опыта
отдельных сотрудников»**: система помнит, что уже пробовали и почему закрыли, и не даёт
вслепую повторить провал — даже если живой сотрудник о нём забыл.

Каждую входящую гипотезу сверяет с «кладбищем» задокументированных провалов:
- 🔴 **красный флаг** — уже пробовали, причина в силе → не повторять вслепую;
- 🟢 **реанимация** — пробовали и закрыли, но **свежий факт снимает причину** → кандидат
  на возврат (напр., реагент был «дорог» в 2012, а в 2021 подешевел втрое);
- ⚪ **чисто** — пересечений нет.

Это **маркер для эксперта**, а не фильтр-«выкидыватель» — решение остаётся за человеком.

## Откуда данные

Домены — во внешних `domains/*.json` (в коде доменных строк НЕТ): `graveyard` (провалы),
`fresh_facts` (снимающие причину), `incoming` (гипотезы), `lift_families`, `generic_terms`.
Идут два домена: `flotation.json` и `alloys.json`. В проде:
- **кладбище** извлекается из реальных отчётов о НИР по фразам-маркерам провала
  («не дало эффекта», «дорого», «нет оборудования», «failed to», «no improvement»);
- **свежие факты** приносит агент-поисковик (новая литература, каталоги поставщиков);
- **входящие гипотезы** приходят из бейзлайнов 01 (LBD) и 02 (диагностика по хвостам).

## Запуск

```bash
python run.py                       # домен по умолчанию (flotation)
python run.py domains/alloys.json   # другой домен — тот же движок
```

**Проверка универсальности:** на `alloys.json` тот же движок ловит закрытое «легирование
рением (дорого, 2013)» и реанимирует его свежим фактом 2022 — без правки кода.

## Что говорить на защите

1. **Институциональная память.** Система хранит грабли за годы и защищает от их повторения
   — то, что обычно живёт только в голове опытного технолога.
2. **Реанимация — уникальная фича.** Не просто «уже пробовали», а «пробовали, но мир
   изменился» → возвращает списанные направления с обоснованием и ссылкой на свежий факт.
3. **Всё заземлено.** Флаг ссылается на отчёт-провал (год, номер) и на снимающий факт.
4. **Связка с генераторами.** Гипотезы «Тонкое грохочение» и «Магнитная сепарация» из
   бейзлайна 02 здесь получают флаги — видно, как генерация и память работают вместе.

## Критерии кейса

снижение субъективности · использование исторических данных · интерпретируемость ·
оценка риска.

## Где агент-поисковик

Свежие факты (`FRESH_FACTS`), снимающие причину закрытия, — это ровно то, что должен
добывать агент-поисковик по каждому провалу из кладбища.
