# Фабрика гипотез — детерминированное ядро

По данным о хвостах обогащения (Excel) строит **граф знаний**, ставит **диагноз** (где и
в какой минеральной форме теряется извлекаемый металл) и выдаёт **ранжированные по деньгам
проверяемые инженерные гипотезы**. Вся логика воспроизводима; LLM — **только** для
полировки текста и ни на что не влияет по существу.

## Главный принцип
> Логика извлечения и метрики **детерминированы** и заземлены в ячейки отчёта.
> Один и тот же файл → тот же граф, те же гипотезы, те же числа. Аудируемо и защищаемо.

## Структура
```
factory/            рабочий пакет (OOP, модульный)
  reader.py         ЧТЕНИЕ    Excel → профиль потерь (openpyxl, по якорям)
  knowledge.py      ГРАФ      networkx: Элемент → Класс крупности → Форма
  rules.py          ПРАВИЛА   диагноз (форма+крупность) → семейство вмешательства
  metrics.py        МЕТРИКИ   ценность = $ в риске, приоритет — арифметика
  generator.py      ГЕНЕРАЦИЯ карточки ЕСЛИ/ТО/ПОТОМУ ЧТО (шаблон)
  llm.py            LLM       Phraser (Yandex) — только оформление, опц.
  report.py         ОТЧЁТ     HTML с графом (SVG) + карточки
  pipeline.py       СБОРКА    HypothesisFactory — единый поток
  evaluate.py       ОЦЕНКА    family-coverage против эталона (детерминированно)
materials/          тестовые материалы кейса (в git не хранятся)
  fabrics/<Ф>/      Хвосты <Ф>.xlsx (вход) + Гипотезы <Ф>.docx (эталон)
  reference/        Как читать отчёт + books/ + schemes/ + regulations/
```

## Установка и запуск
```bash
uv sync                                       # окружение из uv.lock (networkx, openpyxl)

# одна фабрика → консоль + HTML с графом рядом с файлом
uv run python -m factory "materials/fabrics/ТОФ/Хвосты ТОФ_2.xlsx"

# с LLM-полировкой текста (Yandex, ключ в .env). Смысл/метрики не меняются:
uv run python -m factory "materials/fabrics/ТОФ/Хвосты ТОФ_2.xlsx" --polish

# оценка против эталона организаторов (по семействам, без LLM):
uv run python -m factory.evaluate \
  "materials/fabrics/ТОФ/Хвосты ТОФ_2.xlsx" "materials/fabrics/ТОФ/Гипотезы ТОФ.docx"
```

## Доказано на реальных данных (ТОФ)
- Детерминированный проход **~0.04 c**; **$162.7M** извлекаемого металла в риске; 6 гипотез.
- Диагноз верный: `-10` → раскрытый минерал в шламах → грохочение/классификация;
  крупные классы → закрытый Pnt → доизмельчение. Каждое число — до ячейки Excel.
- **FAMILY-COVERAGE эталона = 8/8**, при этом вмешательства **выведены из данных**,
  а не подсказаны модели.

## Почему защищаемо
- Не чёрный ящик: граф, правила и метрики читаются; нет непрозрачных эмбеддингов в логике.
- Grounding настоящий: диагноз привязан к ячейкам; вмешательства — из инспектируемой
  таблицы правил обогащения (эксперт правит), а не из «памяти LLM».
- Ценность в деньгах: приоритет = тонны × цена, а не абстрактный скор.

## Идеи для отрыва на хакатоне
Портфель по 4 фабрикам (единый рейтинг $), прогноз «+X% извлечения → деньги/год»,
дорожная карта эксперимента с оценкой стоимости, интерактивный граф (Cytoscape),
кладбище провалов, обучение на фидбэке, экспорт PDF/DOCX + задачи в Jira/YouTrack.
Главный аргумент: детерминизм + деньги + граф из данных + заземление до ячейки + 8/8
без подгонки — чего нет у «обёрток над LLM».
