# Фабрика гипотез

Команда **discipline ml**
Трек «Фабрика гипотез»
Nornickel Hack 2026

---

Инструмент принимает базу знаний (Excel-отчёты, PDF/DOCX-литературу) и целевой KPI,
на выходе даёт ранжированные проверяемые гипотезы с обоснованием и ссылкой на источник.
Архитектура — гибрид из двух веток с разной природой воспроизводимости, и мы это
не размываем:

- **Ветка А (хвосты) — полностью детерминирована.**
  Ни одного вызова LLM для анализа: тот же файл + схема - побайтово тот же профиль, диагноз и
  метрики. Провенанс до ячейки Excel. Это ядро — на него можно опереться как на расчёт.

- **Ветка Б (литература) — LLM для понимания контекста.** 
  LLM читает неструктурированные источники и предлагает связи. Каждая
  связь проходит цитатный гейт — принимается, только если дословная цитата реально
  есть в источнике. То есть ответ опирается на приведённый источник, а не только на веса
  модели (факт без цитаты отбрасывается). Тип связи берется из закрытого словаря, поэтому
  знак влияния детерминирован. Извлечённый граф кэшируется по отпечатку входа — весь
  downstream (граф, разрывы Свонсона, ранг) воспроизводим.

Про воспроизводимость: сам вызов LLM в ветке Б недетерминирован даже
при temperature=0, поэтому кэш — это мемоизация конкретной выборки, а не гарантия, что
свежее извлечение даст ровно те же связи. LLM не переопределяет детерминированную
ветку А и не участвует в ее выводах.

## Модули подробнее

### Трек А (детерминированный)

- Читает Excel по `ReportSchema`: классы крупности, тоннаж металлов,
  минеральные формы, флаг извлекаемо. Сердце достоверности: все дальнейшее — из этих ячеек.

- Все формат-специфичное знание вынесено в схему; 
  bootstrap предлагает схему для незнакомого отчёта через LLM (разовая задача, не в пайплайне).
  Важно: незнакомый формат без bootstrap не прочтётся.

- Прозрачные доменные правила

- Собирает гипотезы: на каждый класс — диагноз, метрики, эксперимент,
  дорожная карта; `breadth` раскрывает ветви диагноза,
  Важно: при breadth=0 выдаёт ~2 уникальных вмешательства (монотонно, но честно отражает руду).

- Безразмерные метрики (не деньги): `impact` (доля извлекаемых потерь
  фабрики на класс), `addressability` (излечимая доля), `clarity` (доминирование одной формы),
  `confidence` (полнота данных), `feasibility` (нужно ли оборудование). 
  Важно: смотрите глосарий и подсказки

- Три этапа с критериями перехода го/стоп, шаблон по семейству.
  
- Граф профиля потерь и кривая раскрытия по крупности.

### Трек Б (LLM)

- Принимает pdf/docx/xlsx/картинки. Важно: на данный момент схемы-диаграммы как топологию
  не читает — только текст/подписи.

- LLM извлекает связи с обязательной дословной цитатой. Отбор фрагментов по покрытию терминов запроса.
  Важно: выход ограничен окном чтения (max_chunks) и качеством модели.

- Граф связей - разрывы Свонсона +
  прямые связи, ранг = новизна × релевантность × бонус за промышленное действие. Жесткое
  заземление на металл фабрики.

### Обогащения, A×B (в разработке)

- Сшивает диагноз трека А с конкретными узлами из схемы фабрики (данные фабрики с литературой).

- Веб-поиск дословной фразы, где упомянуто вмешательство и металл фабрики.
  Важно: это веб-упоминание, а не проверенное внедрение.

- Научные статьи по гипотезе с цитируемостью, заземлённые на элемент.
  Важно: релевантность ограничена выдачей OpenAlex.

- Привязывает дословные цитаты выданного корпуса к карточкам трека А (IDF-взвешивание - цитата по теме карточки).
  Важно: зависит от наличия релевантного корпуса.

## Метрики

- `impact = извл. тонны класса ÷ Σ извл. тонн по фабрике` — масштаб потери.
- `addressability = извл. тонны ÷ все тонны класса` — какая доля потерь вообще излечима.
- `clarity = тонны доминирующей формы ÷ извл. тонны` — один механизм или размазано.
- `confidence` — полнота данных под гипотезой; `feasibility` — нужно ли новое оборудование.
- `priority = impact·(0.5+0.5·addressability)·(0.7+0.3·clarity)·feasibility·confidence`

## Бенчмарк

- family-coverage recall 27/27 = 100 % (предложены близкие гипотезы с эталонными)
- grounding 100 % (каждая гипотеза привязана к ячейке)
- precision, recall 80/100 % (доля семейств эталонных вмешательств организаторов, воспроизведённых из данных без подсказки)
- LLMasJudje

## Проблемы (честно)

1. Эталон гипотез называет узлы фабрики («6-м мельницы», «насадки 12мм», реагент Finfix 300)
   — это требует знания сземы фабрики. Наши гипотезы — уровня класса вмешательства.

2. Дорожная карта повторяется — не баг генерации, а свойство шаблона.

3. Разнообразие при breadth=0 низкое — отражает руду, но выглядит монотонно. Разнообразие — по слайдеру.
